Welcome to sparse-ir tutorial#

This online document provides comprehensive tutorials of the Python library sparse-ir library and Julia library SparseIR.jl.

This tutorial is part of the sparse-ir ecosystem. Start there for an overview of the libraries (including Rust, the C API and the Fortran bindings) and for the history and comparison of IR, DLR and MiniPole. The Rust versions of these tutorials are in the Rust guide.

The tutorials follow the notation defined on the notation and conventions page of the sparse-ir documentation. The basic theory is explained there as well: the intermediate representation, sparse sampling, the discrete Lehmann representation, and summation over the Matsubara axis.

Please free to make a contact with the authors of each tutorial page if you have any questions!
